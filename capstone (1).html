Cybersecurity Audit Evidence Reviewer

A web application prototype that helps an Internal Audit reviewer organize cybersecurity control requirements and supporting evidence in a dedicated review workspace.

Problem and objective

Managing audit evidence across multiple files can be time-consuming. This prototype centralizes controls and evidence to simplify organization and retrieval.

Core workflow

1. Define controls

Capture the control ID and requirement.

2. Add evidence

Upload synthetic evidence files and check their readiness status.

3. Organize

Manage controls and evidence within the review workspace.

4. Retrieve

Return to saved controls and evidence after refreshing the page.

First pilot

User Access Review (UAR) is the first synthetic pilot scenario. It is not the full scope of the product.

Safety and limitations

Demo data only. Do not upload personal, confidential, or production evidence. Use synthetic data only. The auditor remains responsible for verifying evidence and making audit decisions.

Evaluation

  • Normal test: multiple controls and three evidence files accepted; controls and evidence retained after refresh.
  • Edge test: an empty file was flagged as unreadable; no content was extracted.
  • Messy test: not yet performed.
  • Estimated time: 60 minutes before and 40 minutes targeted after (33.3% expected saving; not measured).

Tools and live prototype

Gemini: planning and specifications. Etlaq: application development and deployment.
