# UI / UX Direction
## Cybersecurity Audit Evidence Reviewer

## Design objective
A clean, professional audit workspace that makes evidence traceability and reviewer judgment more important than decorative AI features.

## Language and layout
- Arabic-first interface with right-to-left direction.
- Keep familiar technical terms in English where clearer (Control, Evidence, Gap, Reviewer).
- Responsive desktop and mobile layouts.
- High contrast, readable typography, clear status labels.
- Avoid dense tables on mobile; convert rows into stacked cards.

## Screen 1 – Home / Dashboard
- Header: product name and “Demo data only” notice.
- Primary action: “Start a Review”.
- Sample review card: “Quarterly User Access Review – Pilot”.
- Small status summary: Controls, Evidence Files, Items Needing Review.
- Short explanation: AI suggestions require reviewer validation.

## Screen 2 – Review Workspace
- Left/top section: list of controls with status.
- Main section: selected control requirement.
- Evidence area: file list, file type, processing status, source preview.
- Action: “Analyze Evidence”.
- Show accepted file types and upload limits before upload.

## Screen 3 – Analysis Results
Use four clearly separated groups:
1. Supporting Evidence – claims with source file and location.
2. Missing / Insufficient Evidence – state only what was not found in supplied files.
3. Potential Inconsistencies – show both sides and references.
4. Follow-up Questions – editable draft questions.

## Screen 4 – Reviewer Validation
- Reviewer status: Not Reviewed / Needs Clarification / Reviewed.
- Editable reviewer notes.
- Actions: Save Review Status, Edit Question, Mark Not Relevant.
- Keep a visible “AI draft – human review required” notice.

## Screen 5 – Export
- Preview report.
- Export draft as Markdown or CSV.
- Include scope, files reviewed, limitations, and reviewer decisions.

## Visual direction
- Neutral light background, dark readable text, restrained blue/teal accents.
- Use red/orange only for meaningful risk or warning states.
- Avoid using color alone to communicate status; include text labels/icons.
